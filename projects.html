Key Features:
  • Multi-Role IT Service Desk (/portal) with dedicated operational consoles for Enterprise Admin, Service Coordinator, Field Engineer, Client IT Support, and Individual Clients

System Architecture:

High-performance Node.js & Express 4.x RESTful backend paired with a self-healing MySQL / MariaDB database (automated runtime schema integrity, composite indexes, and utf8mb4 collation). Pure Web Standards frontend (Semantic HTML5, CSS3 design tokens, modular Vanilla JavaScript, PWA) deployed on Hostinger Cloud with LiteSpeed/Apache .htaccess rules, PM2, and a 50-category defensive security posture.

Fake News Detector

Fake News Detector — Fake News Detector

An advanced Natural Language Processing (NLP) system designed to detect and classify deceptive or fabricated news text. Utilizes pre-trained Sentence-Transformers (all-MiniLM-L6-v2) to extract dense semantic embeddings from news headlines and body text, classified via trained ML models on the 72,000+ article WELFake dataset with an interactive Streamlit UI.

Key Features:
  • Dense Semantic Sentence Transformers embedding extraction using all-MiniLM-L6-v2
  • High-accuracy classifier model trained on the comprehensive WELFake dataset (72,000+ articles)
  • Real/Fake classification with real-time probability confidence score breakdown
  • Feature scaling pipeline with persistent .pkl model artifact caching for fast predictions
  • Interactive Streamlit web interface (app.py) for live text pasting and immediate verification
System Architecture:

Python NLP pipeline using Sentence-Transformers for semantic vectorization, Scikit-Learn classifier with feature scaling, and Streamlit for reactive web application rendering.

Technologies & Tools: Python, Sentence-Transformers, Scikit-Learn, Streamlit, Joblib, NumPy, NLP
